Справочник полей результата

📋 Базовые поля размещения
  • id — Идентификатор размещения (берётся из placementId).
  • isin — Международный код бумаги (ISIN).
  • ticker — Биржевой тикер (берётся из symbolObject).
  • issuer — Эмитент / название инструмента.
  • type — Тип инструмента (берётся из subPlacementType: «Облигации», «ЦФА» и т.д.).
  • status — Статус размещения (active, и т.п.).
📅 Блок dates (Даты)
  • start — Дата начала сбора заявок (startDate).
  • end — Дата окончания сбора заявок (endDate).
  • maturity — Дата погашения (maturityDate).
💰 Блок financials (Финансовые параметры)
  • couponMin — Минимальная купонная ставка, %.
  • couponMax — Максимальная купонная ставка, %.
  • nominalValue — Номинальная стоимость одной бумаги (из nominal.value).
  • nominalCurrency — Валюта номинала (из nominal.currency).
  • minInvestment — Минимальная сумма инвестирования (minSumInvest).
🚦 Блок restrictions (Ограничения)
  • qualifiedOnly — true, если доступно только квалифицированным инвесторам.
  • iiAAllowed — true, если разрешено покупать на ИИС (isAllowForIIA).
📝 Прочее
  • description — Описание размещения (как в исходных данных).
  • Поля nominal*, coupon*, minInvestment могут быть null, если в источнике их нет (например, для ЦФА).
